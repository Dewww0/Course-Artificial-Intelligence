# Course Artificial Intelligence

Repository ini dibuat untuk memenuhi tugas mata kuliah Artificial Intelligence (AI).

## Daftar Proyek

### 1. Expert System
Program sistem pakar yang menggunakan aturan dan fakta untuk menghasilkan diagnosis atau rekomendasi berdasarkan input pengguna.

### 2. Search Algorithm
Program algoritma pencarian yang digunakan untuk menemukan data atau mencari jalur menuju tujuan tertentu.

## Bahasa Pemrograman
Python

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal.
2. Unduh atau clone repository ini.
3. Buka terminal pada folder proyek.
4. Jalankan file Python sesuai program yang ingin digunakan.
